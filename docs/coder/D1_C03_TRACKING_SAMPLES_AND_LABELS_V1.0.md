# D1 C03 跟踪路线与最少标注集

日期：2026-10-05；状态：研究与标注协议完成，真实质量 NOT_RUN，P0 未通过。

现有平台 FaceDetector 和自有模板跟踪只作对照。平台 API 不随本项目分发第三方模型文件；现有入口在宿主执行，尚未迁移进批准的媒体 worker。模板方案只有平移搜索、歧义拒绝、丢失、revision 与手工纠正；C02 的五个合成例子按原 hash 复用，没有再次运行或冒充真实样本质量。

## 路线决定

| 路线 | 本轮准入决定 | 技术与权利差距 |
| --- | --- | --- |
| Android FaceDetector | 允许现有可行性对照；不作为最终自动人脸能力 | 正面、低分辨率、遮挡、侧脸、多人持续性均无标注证据；原入口只统计候选数量 |
| 自有传统模板跟踪 | 允许继续实现，不引入外部权重 | 当前 ROI 4–32、搜索 ±24、0.80/0.05 是实验参数；未实现尺度金字塔、旋转、多目标关联、相似目标交叉与出画重入。不能冻结质量阈值 |
| ML Kit bundled face detection | 候选研究，未下载 AAR/权重或集成 | [官方 Android 文档](https://developers.google.com/ml-kit/vision/face-detection/android)区分 bundled 与动态下载；[条款](https://developers.google.com/ml-kit/terms)把模型视为相关软件并规定使用约束，同时说明可能联系服务器并发送性能/使用指标。未证明符合本项目离线、无遥测及 SDK 再分发要求，须具体条款和离线策略审核 |
| Zoo YuNet / ViTTrack 指针 | 保持禁止集成 | 复用 C02 精确指针、训练配置和权利缺口证据；没有把下载页许可证当作训练数据、预训练与实际 checkpoint/export 的完整权利链 |

没有识别人脸身份的需求或实现。target_id 只在单个 clip 内关联区域。

## 最少样本申请

需要 10 个权利明确的本地短片，每片 15–30 秒；原样本不上传，不从网络随意下载人脸素材。每片提交授权来源、允许的测试/复制/标注范围、SHA-256、实际 codec/尺寸/方向/PTS，不以文件名推断格式。

| clip | 必须覆盖事件 |
| --- | --- |
| F01 | 单人正面平移与快速移动 |
| F02 | 多人、相似外观交叉、目标 ID 不互换 |
| F03 | 侧脸与低光、部分遮挡 |
| F04 | 人脸尺度变化与旋转 |
| F05 | 完全遮挡、出画、重入；不自动接续未知身份 |
| O01 | 手选物体平移、背景纹理变化 |
| O02 | 物体尺度与旋转 |
| O03 | 遮挡后手工纠正，旧 revision 不能覆盖新轨迹 |
| O04 | 多个相似物体交叉与分离 |
| N01 | 无目标/负例、竖屏旋转元数据及 VFR |

当前这 10 个 clip 与真实人工标签均 **未取得**。现有视频能支持读取/字幕测试，不能视为已获上述标注、人物测试授权或质量通过。

## 标注格式与门禁

模板见 `d1c03/labels/annotation-template.json`，只是空白示例，不是真实标签。每个 frame 用解码得到的 presentation timestamp `pts_us`，同时保存 frame_index、方向归一后的显示 width/height；不要用固定 FPS 推算 VFR 时间。

每个 target 使用 clip 内随机 ID、类别 FACE/OBJECT、revision、人工框 `[x,y,width,height]`（0–1、显示坐标）、visibility：VISIBLE、PARTIAL、FULLY_OCCLUDED、OUT_OF_FRAME、UNOBSERVED。遮挡/出画可无 box，必须保留原因。纠正记录 corrected_at_pts_us、old/new revision，旧结果不可覆盖新结果。未标注不等于保护成功，LOST/歧义/未观测区间必须显式暴露，不能插值成已验证覆盖。

D1 最少在每片关键事件附近连续标 100 个实际帧，合计至少 1000 帧，仅用于技术路线可行性；它不替代正式输出逐帧保护验证。标注者与复核者独立记录；分歧裁决后冻结标签版本和 hash。记录漏检、误检、ID 切换、框覆盖、尺度误差、纠正延迟和丢失区间，按场景分层报告，不能只报总体平均。

M5/M6 再验证完整 clip、多目标、尺度、纠正、重入策略及性能；正式导出保护要对应实际输出 PTS 逐帧核查。自动人脸、手选物体、多目标及纠正的 P0 门禁保留，不能用本协议或合成通过替代。
