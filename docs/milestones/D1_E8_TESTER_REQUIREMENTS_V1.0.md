# D1 E8 tester requirements V1.0

2026-10-17。独立设计评审四文档与需求证据矩阵，不设备/构建/媒体/迁移执行。核历史终局证据与当前liveproof分离，合作故障模型不冒充同UID对抗安全；无需不必要的防回滚根，但主动篡改能力和保证限制必须真实。

评选一次性精确终局验收/迁移，保全V1档案、预算identity、107218消费、原三笔终局R/S与产物，不清账/换账户/删除/补造birth或原closeACK。核当前guard/fence/账本/无pending/当前进程及原资源真实返回与失败关闭，明确哪些检查能因终局验收不再每host重做。

核V2可实现事前boot/start采样、参与进程及FD传递、单调时限、close UNKNOWN、崩溃/部分提交/重放/回滚和跨重启，避免持久“自身closeACK”循环论证。明确不可逆动作审批准确对象/风险/保留/验证，及无足够证据时隔离步骤，不把人类批准当实际资源证据。

本批只有设计与既有元数据有限离线论证，未实现迁移或V2，不能登记生产/Android测试通过。原E7A只支持快完成/ACK实测，长期准入仍OPEN、D1未过/M0未启、P0许可保持。评审报告负责人；coder交付后按用户要求暂停，不自动新批。
