- 核对三个APK的路径、长度/SHA-256、Debug/Test/Release组成、minSdk31、构建任务与候选关联；不重跑Gradle，不安装APK，不操作设备。

- 对照真实媒体清单：新增AVI/SRT、内嵌ASS存在；单帧GIF/WebP不能作为动态图通过。元数据探测和实际Android解码分开，样本许可只限授权测试不自动可分发。
