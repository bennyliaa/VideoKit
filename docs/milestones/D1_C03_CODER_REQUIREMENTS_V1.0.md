## 完整任务批次

1. 将实际有风险的媒体读取/探测与至少一个真实编码或帧提取路径接入受控worker/broker，不能只有SIGSEGV探针孤立运行而真正管线仍在宿主。记录实际权限、数据所有权、Surface/descriptor跨进程路径、生命周期和回收。若平台能力不可行，提交具体接口限制/实验和等价隔离替代方案，不把方案文本当完成。
2. 补实际编码进行中取消（有处理进度后取消，不只start后立即cancel）、实际本测试宿主/worker终止恢复、同task未知ready查询、跨owner恢复及取消竞态入口。测试入口仅作用于本应用/本worker，不杀无关进程；源只读、不完整输出不ready。测试包成组准备，暂不安装设备。
3. 实现或明确协议处理close失败后的受控重试/查询、非协作I/O队列耗尽、真正排空与SourceReleased证据边界；不能仅返回timeout就宣布资源释放。回收有界、任务ownership可验证。
4. 逐条分析16个工具漏洞实际可达性、官方修复与兼容处置，形成依赖安全决定和复查依据。不盲强制AGP内部传递版本；精确证据支持限制使用/升级/待平台修复等处置，不用“非runtime”自动豁免。不重新扫描和编译无变化组件。
5. 负责人允许继续研究合法可用的人脸检测/物体跟踪路线；优先复用权利清晰的组件，权利不清权重仍不得集成。平台FaceDetector+模板跟踪只作为对照/可行性路线，不能以5个合成例子替代完整P0。提交最少样本和人工标注规范，以及满足多目标/尺度/纠正/丢失需求的技术差距；无法独立取得样本或权利时列具体需求，避免无目标反复查同源。
6. 输出M0可冻结与不得冻结列表：只冻结已有可行性证据的源/输出/状态/句柄语义，设备数值、跟踪最终质量和未实现平台能力继续在对应正式阶段验收。D1应证明关键架构可行，不要求在D1提前完成M1–M8全部产品功能，但关键不可行问题必须明确处置，P0最终门禁不变。
