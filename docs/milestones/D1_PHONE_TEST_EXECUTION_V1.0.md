若需C03补测则写WAITING_FOR_FIX_CANDIDATE，不宣称手机全部完成。负责人结合报告通知用户手机实际测试结论和下一步切换安排。平板必须等用户切换后再派发，不自动操作其他设备。D1完整退出仍需有关真机/源安全/输出/隔离等证据，手机批次完成不等于D1通过。
