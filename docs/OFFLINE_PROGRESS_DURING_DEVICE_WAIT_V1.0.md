# 设备占用时并行离线推进规则 V1.0

适用前提：用户明确恢复项目并由负责人正式派发后才执行。当前PAUSED_WAITING_USER，设备等待规则不授权暂停期间开发/测试或占用查询。历史工作单见归档，当前状态见CURRENT_DESIGN_BASELINE。

2026-10-20 用户最新明确要求：真机被其他项目占用时，设备测试记ENV_WAIT，不能让coder和tester一起停工等待。负责人优先从现阶段未完规划中派不依赖真机的完整开发批，tester并行对已冻结来源进行离线测试/审查及独立用例准备；不能审浮动源码或把本机PASS冒设备PASS。开发目录、测试证据和构建占用分开，tester不得与coder并发Gradle/共享可变缓存。新包完整自测冻结后一次整包交测，缺陷集中修复回归。真机可用再派准确批次，不操作其他项目、不连续ADB轮询。此规则覆盖此前因设备占用要求双方全面冻结的安排；冻结候选仍保留，未交付的后续开发在新目录进行。D1未过M0未启，M0后每批1–3里程碑、Flutter自有Theme及SkinKit延期不变。
