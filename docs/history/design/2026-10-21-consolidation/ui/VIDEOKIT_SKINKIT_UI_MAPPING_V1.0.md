## 最新有效决定：Flutter 自有 Theme，SkinKit 延后（2026-10-20）

先使用 Flutter 开发自有 VideoKit Theme 和完整 App UI，按既有 PPT 样式实现；等 SkinKit 正式支持 Flutter 后再评估并安排集成。当前不做 SkinKit Android 原生桥接，也不以其真实接入作为 M0/M8 的既定退出门。本条覆盖下文此前“暂不自建 Theme”“M0 必须实接 SkinKit”等旧要求；供应方资料与历史要求保留供将来评审，不作为当前强制任务。完整现行范围见 [Flutter Theme 与延后集成决定](../FLUTTER_THEME_AND_SKINKIT_DEFERRAL_V1.0.md)。完整 UI 优先、演示数据隔离、后续功能接回以及每批 1–3 个里程碑的集中开发测试规则不变；当前 D1 冻结任务不变，M0 未启动。


## M0 UI 优先实施要求（2026-10-20 最新）

用户最新决定（2026-10-20）：M0 在保留 API/Fake/TestKit/sample-host 原范围的同时，先搭建整个正式 Flutter App 的 UI 框架，按既有 18 页 PPT 的视觉与交互样式实现，并真实集成 SkinKit。允许生成带明确“演示模式·模拟数据”标识的本地测试数据演示全部主要页面与状态；演示不能冒充真实播放、跟踪或导出通过。后续 M1–M6 功能逐批实现并接回同一 UI，M7 保持独立宿主接入，M8 完成全功能真实集成与发布级验收，不再首次重建 UI。继续复用 SkinKit 默认/标准样式与合法最小宿主适配，不另建独立 Theme 系统、主题包或编辑器；通过既有配置与受支持的最小覆盖实现 PPT 样式，无法表达的差异列明评审。

完整范围与退出门槛：[M0 App UI 框架要求](../M0_APP_UI_FRAMEWORK_REQUIREMENTS_V1.0.md)。本次为规划更新；D1 尚未通过，M0 尚未启动，不改变已冻结候选或当前设备批次。

## 1. 本阶段视觉来源

按 PPT 的深空蓝、青绿点缀、清晰层级与克制科幻感实现页面；使用 SkinKit 既有默认/标准样式、受支持配置及最小宿主适配，保留真实 Provider 与回退，不另造主题系统或 skinpack。页面结构、圆角、间距、状态及手机平板布局按 PPT 与 M0 总要求逐项建立映射。

## 2. 页面与已有样式适配

| 页面 | 复用方式 | App 保持的职责 |
| --- | --- | --- |
| 本地首页/导入 | 已有 button/card/list/icon/typography 标准 Token | 文件授权、最近列表、页面结构 |
| 播放/轨道/图片 | 现有按钮、进度、Sheet、表面和文本样式 | Seek/轨道/手势、内容帧与图片变换 |
| 多画面 | 标准容器、边框、选中态和警告样式 | 独立槽位、唯一声音、预算与降级 |
| 编辑/跟踪 | 标准颜色、尺寸、状态与组件样式组合 | 时间线、选区、轨迹与安全纠正 |
| 导出/错误 | 标准进度、主次按钮、错误状态 | Sink/提交/取消与真实终态 |
| 设置 | 供应方已有主题和显示模式配置 | 语言/可访问性、实际可用入口 |

不预先注册 `apps.videokit.*` 自有样式体系。确有必须业务控件无法表达时，列出当前 API/Token 缺口与最小适配方案另评审；不绕过 Provider 写散落颜色，也不自行复制 Contract。

## 3. 设置页补充

外观设置明确分为“主题”和“显示模式”。主题页使用 SkinKit 已提供默认/标准主题及已验证本地主题、当前选择、隔离预览、显式应用、恢复默认及本地主题包选择入口；显示模式支持跟随系统/浅色/深色并持久化。已有默认主题永久可选、本地恢复不联网。

本地选择只触发校验/安装，不自动应用；应用失败保留上一可用主题。未选 Commerce/Store 时不展示商城、价格或购买入口。供应方九个 demo 不等于正式包内九个主题。Personal/Creator/照片主题和角色动画不是此次默认新增产品功能。

## 4. 组件与平台约束

公共组件从 Adapter 取得同 generation 的类型化已解析值，转换到 Flutter ThemeData/ThemeExtension；禁止业务页直接读任意 Map 或跨通道逐 getter 读取。按钮、输入、Sheet、导航和时间线状态完整，loading 映射宿主状态。

48dp 热区、安全区、窗口断点与焦点/读屏语义由 App 维护，皮肤只能影响合法视觉字段。Glass 先使用 Solid；不把半透明色当作真正 backdrop blur。照片上的文字/图标保护层独立验证。减少动画、后台与多画面资源压力优先业务可用。

手机/平板/桌面不靠皮肤更换业务布局，RTL 与大字体仍按 UI 适配规则重排。主题不可改变字幕内容、媒体色彩空间、遮罩导出强度或安全输出验证，不能以“主题”把业务异常隐藏成成功。

## 5. 定稿与验收

UI 正式集成需附页面→公共组件→供应方已有合法 Token/样式→默认模式→各状态→回退测试对照，以及真实 Flutter 截图/设备记录。现有 18 页 PPT 作为当前页面与视觉实现依据保留，后续改版须保留 SkinKit 接线说明及版本记录，不将本补充文字冒充已生成的新效果图。
